Konclave benchmark

What scanning and proving a Zcash shielded wallet cost in this browser, on this device. This is the acceptance check of Milestone 1 of the Konclave grant; the full instructions are in the reviewer sheet.

Open the Milestone 1 review build (656e967)

The build is the web/ folder of the release zip konclave-benchmark-656e967.zip, published unchanged (zip sha256 5aa53dc4a8a589a9b384be650c2262189e9088886bf6a576315f2bf199070165). Its header shows "Harness wasm 656e967 ... page script 656e967". The main page runs on one thread, as the verdict rows did. Its "Threads page" link tries to turn threads on with a service worker, since this host cannot send the isolation headers; the "Mode:" line in its header says whether it worked (on the A72's Chrome it did not).

What leaves your device

Results stay in the browser until you press "Copy all"; nothing is sent to us. A scan row calls the light client server you type (for example https://zec.global, run by Zingo Labs): that server sees your IP address and the range of blocks you ask for, as it would for any wallet. Never paste a key of your own: use only the published test key below.

The published test key

A view-only key of a test vault, published in the repository (config/test-vault.json). It cannot spend.

Rows from this page

A row run here through zec.global is information, not a verdict: the verdict rows of the results table went through the project's proxies. Compare the median with the class of your device in the reviewer sheet.
