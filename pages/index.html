Konclave · Milestone 1 review

Konclave benchmark

Measure what scanning and proving a Zcash shielded wallet cost in this browser, on this device, and compare it with our results. Nothing to install. Two rows take from about 6 minutes on a high-end phone to about an hour on an entry phone.

  1. 1

    Copy the published test key

    A view-only key of a test vault, published in the repository (config/test-vault.json): 195 characters, starts with uview1. It cannot spend. Never paste a key of your own.

  2. 2

    Open the review build

    It opens in a new tab, so these steps stay here. Its header must show "Harness wasm 656e967 ... page script 656e967"; if it shows anything else, stop.

    Open the build (656e967)
  3. 3

    Fill the top of the form

    Close other apps and tabs. Type the device (model and RAM), pick the class (phone or laptop), and type the device's temperature in °C. The build prints a median only for runs that carry a temperature: without one, each run's time still shows but the row prints no median. On a phone, use the battery temperature; the reviewer sheet reads it with a computer. Without a temperature, a row from this page is a set of run times with no median. Leave "Runs per row" at 5 and Threads off.

  4. 4

    Run the proof row

    Tick Prove, untick Scan, and tap Run. A 2-action Ironwood proof is built 5 times.

  5. 5

    Run the one-day scan row

    Untick Prove, tick Scan, and set "This range is" to "one day of blocks (3,456)": the default, "other", scans the heights typed below it, which start empty, and every run fails. Then paste the key into "Viewing key to scan with", type https://zec.global (run by Zingo Labs) into "Or a live light client endpoint (gRPC-web)", and tap Run.

    Keep the screen on and the page in front while a row runs: switching away, locking the screen or reloading is recorded and the run does not count.

    If the build was reloaded or opened again, fill step 3 again: the form goes back to its defaults.

Compare

Each row prints a median when its runs carry a temperature; otherwise compare the run times. Compare them with the device of our results table nearest to yours, in the reviewer sheet. The proof row is the same test as our verdict rows. The scan row from this page is information, not a verdict: our verdict scan rows went through the project's proxy, which answers only a copy of the page served on your own machine.

What leaves your device

Results stay in the browser until you press "Copy all"; nothing is sent to us. GitHub Pages, which serves this page, sees the visit.

The scan row calls the light client server you type: that server sees your IP address and the range of blocks you ask for, as it would for any wallet.

Details for checking the build

The build is the web/ folder of the release zip konclave-benchmark-656e967.zip, published unchanged after its sha256 was checked (5aa53dc4a8a589a9b384be650c2262189e9088886bf6a576315f2bf199070165) and every file compared with the zip.

The main page runs on one thread, as the verdict rows did. Its "Threads page" link tries to turn threads on with a service worker, since this host cannot send the isolation headers; the "Mode:" line in its header says whether it worked.

Source, method and results: github.com/deegalabs/konclave-benchmark.
