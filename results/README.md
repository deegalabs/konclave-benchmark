# Results

This folder holds the project's own runs under the protocol: the raw JSON the page gives ("Copy all"), unedited, one file per session. It is empty today: no verdict run has been made.

A run in this folder is a verdict only when `node scripts/summarize.mjs results --commit <commit>` gives it one; every number in the README's results table is recomputed from a file here. Results from other people go in [community-results/](../community-results/README.md) and are information only.
